# Freight Rate ML Assessment

This repository contains a reproducible freight-rate regression baseline, temporal validation, predictions for the 12,000 validation loads, and a December prediction chart.

## Contents
- `solution.py` — feature engineering, October temporal holdout, CatBoost training, validation predictions, December predictions and feature-importance chart.
- `score.py` — supplied assessment scorer; validates the final CSV and generates the required fixed-input December chart.
- `requirements.txt` — Python dependencies.
- `outputs/validation_predictions.csv` — required `load_id,predicted_rate` output (12,000 rows).
- `outputs/validation_metrics.json` — held-out October metrics.
- `outputs/december_prediction_chart.png` — December 1–31 chart generated by the supplied `score.py`.
- `outputs/december_chart_inputs_completed.csv` — 31 fixed-lane inputs with the model predictions added, in the exact column order required by `score.py`.
- `outputs/scorer_results/candidate_december.png` — exact scorer-generated chart.
- `outputs/feature_importance.png` — model feature importance plot.
- `outputs/freight_rate_catboost.cbm` — final model trained on all labeled rows.
- `report.docx` — assessment report.

## Setup
Python 3.10+ recommended.

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
```

Place these supplied files in the repository root:
- `train-test.csv`
- `validation.csv`
- `validation-predictions-template.csv`
- `december-chart-inputs.csv`

Then run:

```bash
python solution.py --train train-test.csv --validation validation.csv --template validation-predictions-template.csv --december december-chart-inputs.csv --output-dir outputs
```

The script verifies that the template's `load_id` sequence matches validation data, predicts every row, and writes the required output. Do not train on validation labels; none are supplied.

To validate the submission and generate the required chart with the supplied scoring script:

```bash
python score.py --predictions outputs/validation_predictions.csv --december-predictions outputs/december_chart_inputs_completed.csv --output-dir outputs/scorer_results
```

The script has been run successfully on the included outputs; it validates all 12,000 expected IDs and all 31 December dates.

## Modeling approach
- CatBoost regression to handle categorical pickup, delivery, equipment, and route features without one-hot exploding high-cardinality city/route values.
- Numeric inputs include distance, weight, coordinates, market index and quote signal, plus date-cycle and weight-per-distance features.
- Missing numeric values are left as missing for CatBoost's native handling; missing categories become `Unknown`.
- Chronological holdout: train on January–September 2025 and evaluate on October 2025. After measuring holdout performance, refit on all labeled development data for final predictions.
- Non-negative output clipping protects against physically implausible negative rate predictions.

## Important caveats
- The December chart inputs omit coordinates, `market_index`, and `quote_signal`, so the model handles those features as missing for this fixed-lane chart.
- The October holdout is a single chronological validation window; rolling-origin validation could provide a more robust estimate.
- The data files are not bundled into this repository archive. Keep them local or follow the employer's data-sharing rules before pushing data to a public GitHub repository.
